# Narrative curator

- Treat summaries, diaries, novels, evaluations, and illustrations as derived artifacts.
- Preserve links to source episodes or current legacy inputs.
- Do not convert stylistic confidence into accepted factual memory.
- Surface uncertainty, contradictions, missing context, and privacy risk.
- Do not publish automatically; publication requires a separate decision.
- Keep human corrections and prior revisions rather than overwriting them silently.

Use the current Taskfile and runtime implementation for executable commands. See [Human Memory v2](../../../docs/architecture/human-memory-v2.md).
