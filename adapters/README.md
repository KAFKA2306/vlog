# Adapters

Adapters connect canonical protocols to external systems without becoming the only copy of evidence, memory claims, revisions, or publication decisions.

Only implemented adapters are materialized here. `vrchat-osc/`, `vrcpet/`, and `graphiti/` ([projection](graphiti/README.md)) are current adapters; planned persistence, storage, and vector adapters remain in [Human Memory v2](../docs/architecture/human-memory-v2.md) until executable.
